A — Deploy & Run Intake Hold: pivots intake down and spins rollers on. Release: stops.
Y
Y — Retract Intake Hold: pivots intake up to retracted position. Release: stops pivot.
B
B — Reset Gyro Zeroes heading while keeping current XY pose. Works while disabled.
X
X — X-Lock Drive Stops the robot by angling all swerve modules into an X pattern.
LB
Left Bumper — Intake Reverse Hold: spins intake rollers in reverse to unjam. Release: stops.
RB
Right Bumper — Shoot Spins up launcher → waits for target RPM → runs indexer + launcher. Release: stops both.
LT
Left Trigger — Indexer Reverse Hold: runs indexer in reverse to unjam. Release: stops indexer.
RT
Right Trigger — Wiggle Intake Hold: oscillates intake pivot to shuffle game pieces into indexer.
